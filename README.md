Đề Tài: Hệ Thống Quản Lý Mượn Trả Thiết Bị
Giới thiệu
Hệ thống hỗ trợ Giảng viên và Sinh viên đăng ký mượn/trả thiết bị giảng dạy, tích hợp phân quyền và quản lý lịch sử duyệt cho Admin.
Công nghệ sử dụng
- PHP (Backend)
- MySQL (Database)
- HTML5, CSS3, JavaScript, Bootstrap (Frontend)
- Môi trường chạy: XAMPP / Apache / Localhost
